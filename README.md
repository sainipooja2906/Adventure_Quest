🏕️ Adventure Quest – Text-Based Python Game
🎮 Overview

Adventure Quest is an interactive console-based adventure game built using Python and Object-Oriented Programming (OOP) principles.
The player explores multiple paths — forests, rivers, and mountains — encountering random events that can either heal or harm them.
The ultimate goal is to find the hidden treasure before your health runs out!

🚀 Features

🧠 Object-Oriented Design: Uses Player and AdventureGame classes for modular and structured code.

🎲 Randomized Gameplay: Each run generates different outcomes for caves, forests, and rivers.

❤️ Health System: Player health changes dynamically based on choices and random events.

💾 Save & Load Progress: Player data (name and health) is stored in a local file (savegame.txt).

🗺️ Multiple Paths & Endings: Explore, survive, or perish based on your decisions.

⏱️ Timed Dialogue Effects: Adds realism with short pauses using the time module.

🧩 Game Objective

Navigate through different areas — the forest, mountain, and river — while keeping your health above zero.
Discover the hidden treasure inside the cave to win the game!

🏆 Winning Path Example:
Start → North (Forest) → North (Mountain) → Enter Cave → Find Treasure → WIN

⚙️ Technologies Used

Language: Python

Concepts: Object-Oriented Programming (OOP), Randomization, File Handling, Loops & Conditionals

Modules: random, time, os

💻 How to Run

Clone or Download this repository.

Open a terminal or IDE (like VS Code or Google colab).

Run the game:

python adventure_quest.py


Enter your name and start your adventure!
